and License.rtf in the Windows installer).

This file lists the third-party, open-source components NASsie uses and,
where applicable, actually bundles into a distributed build. It's provided
as a standard third-party notice, not a legal opinion - if you need a
formal license compliance review, get one from someone qualified to give it.

Scope
-----
- Windows (NASsie.msi / NASsie.exe): built with PyInstaller (--onefile),
  which bundles the components below directly into the distributed
  executable - see packaging/windows/build.ps1's --collect-all flags for
  the exact list.
- Linux (the .deb package): none of these are bundled into the .deb at
  all. python3-pyside6.*, python3-rich, and python3-qrcode are installed
  as separate apt dependencies (see the "Depends"/"Recommends" fields in
  packaging/deb/nassie/DEBIAN/control) - apt and each package's own
  Debian maintainer handle that packaging and its own license compliance,
  independent of NASsie. Nothing here needs a notice on that platform.
- macOS: no packaging currently exists (source-only).
